Project Description

The Introduction to the 3D Animation Pipeline explores computer animation in a professional production pipeline, giving students hands-on exposure to key animation roles through short sprints covering design, modeling, rigging, animation, lighting, and rendering.

Process

I started building the character with primitive shapes in Maya. I wanted to follow the process I have been thought in the live drawing sessions I have attended, which is to start with the most basic shapes and lines of actions, and add details later.

I imported the face model to Zbrush, where I started sculpting model. It was my second time sculpting in Zbursh, so it took me time to learn the tools. However, I got the hang of it eventually.
